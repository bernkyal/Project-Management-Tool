How to Run the Project Using PyCharm

1. Uncompressing the submission
Download the submitted ZIP file and extract all contents to a folder on the computer.

2. Opening the project in PyCharm
Open PyCharm on the lab computer.
On the welcome screen, select “Open” and choose the extracted project folder.
PyCharm will load the project automatically.

3. Setting up Python interpreter (if prompted)
If PyCharm asks for a Python interpreter:

Choose an existing Python 3 interpreter available on the lab machine, or

Allow PyCharm to configure one automatically.

No external libraries are required.

4. Running the application
In the Project view, locate the file named main.py.
Right-click on main.py and select Run ‘main’.

The command-line interface will appear in PyCharm’s Run window and can be used to interact with the application.
